Tutorial: Quiz Interactivo

Aprende a crear un quiz con HTML, CSS y JavaScript paso a paso.

Paso 1 — Estructura HTML

Primero definimos el formulario con las preguntas. Cada pregunta usa un <label> y un <input> de texto. 

<form id="quizForm">
  <div class="question">
    <label>1. ¿Cuál es la capital de Francia?</label>
    <input type="text" id="q1">
  </div>

  <button type="button" onclick="checkAnswers()">
    Comprobar
  </button>
</form>

<p id="result"></p>

El atributo onclick conecta el botón con la función JavaScript que evaluará las respuestas.

Paso 2 — Estilos CSS

Usamos CSS para dar estilo al formulario: bordes redondeados, colores claros y transiciones al enfocar los campos. 

.question input[type="text"] {
  width: 100%;
  padding: 8px 12px;
  border: 2px solid #dce1e8;
  border-radius: 6px;
  transition: border-color 0.3s;
}

.question input[type="text"]:focus {
  border-color: #2980b9;
}

La clase .feedback muestra texto verde o rojo según si la respuesta es correcta o no.

Paso 3 — Lógica JavaScript

La función checkAnswers() recorre un arreglo de respuestas correctas, compara con lo que el usuario escribió y muestra retroalimentación. 

const answers = {
  q1: "paris",
  q2: "oxigeno",
  q3: "7"
};

function checkAnswers() {
  let score = 0;
  const total = Object.keys(answers).length;

  for (const [id, correct] of Object.entries(answers)) {
    const input = document.getElementById(id);
    const value = input.value.trim().toLowerCase();

    if (value === correct) {
      score++;
      // mostrar feedback positivo
    } else {
      // mostrar feedback negativo
    }
  }

  // mostrar resultado final
}

Usamos trim() y toLowerCase() para que la comparación no dependa de mayúsculas o espacios extra.
